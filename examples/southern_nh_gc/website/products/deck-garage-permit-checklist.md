# Southern NH Deck & Garage Permit Checklist

**O'Sullivan Construction & Property Management**  
For homeowners in Nashua, Manchester, Merrimack, Bedford, and surrounding southern New Hampshire towns.

---

## Before you visit town hall

- [ ] Property address and parcel ID (from tax bill or GIS map)
- [ ] Current mortgage holder name (some towns ask)
- [ ] HOA contact info if applicable
- [ ] Rough sketch or dimensions of proposed deck/garage
- [ ] Contractor name and NH license number (if hired)

---

## Deck permit checklist

### Plot / site plan

- [ ] House outline with door/window locations near the deck
- [ ] Proposed deck outline with dimensions
- [ ] Setbacks from property lines labeled (side, rear, front)
- [ ] Easements and septic shown if on your lot
- [ ] North arrow and scale

### Structural details towns commonly require

- [ ] Footing size and depth (**48" below grade** is typical in southern NH frost zones)
- [ ] Ledger attachment method (bolts, flashing, rim joist detail)
- [ ] Joist size, spacing, and span
- [ ] Beam size and post locations
- [ ] Railing height (**36" min** at walking surface; check local amendments)
- [ ] Stair rise/run and handrail/guard details

### Materials

- [ ] Decking type (pressure-treated, composite, etc.)
- [ ] Fastener note (corrosion-resistant at PT contact)

### Inspections (typical order)

1. Footings (before pour/backfill)
2. Framing
3. Final

*Your town may vary — confirm at permit pickup.*

---

## Detached garage permit checklist

### Plot plan

- [ ] Garage footprint with dimensions
- [ ] Setbacks from all property lines
- [ ] Driveway/access path
- [ ] Distance from house (fire separation / town rules)

### Foundation

- [ ] Slab on grade **or** frost wall to depth per town
- [ ] Anchor bolt pattern if slab
- [ ] Frost wall height and footing width if used

### Structure

- [ ] Wall height and roof pitch
- [ ] Door opening size and type (overhead, man door)
- [ ] Window locations if any

### Electrical (separate permit often required)

- [ ] Panel location and amperage if adding service
- [ ] Lights, outlets, garage door opener circuit
- [ ] Licensed electrician on permit if required locally

### Inspections (typical order)

1. Footings / foundation
2. Framing / rough
3. Electrical rough (if applicable)
4. Insulation (if heated space)
5. Final

---

## Questions to ask your building department

1. What is the minimum setback for an accessory structure in my zone?
2. Is a plot plan from a surveyor required, or is a hand sketch OK?
3. Are there height limits for garages or deck railings?
4. Do I need separate electrical and building permits?
5. How long is the permit valid if I don't start right away?
6. Does my HOA need approval before you will issue a permit?

---

## Red flags that delay permits

- Setback too tight — need variance (adds weeks)
- Work over septic or well setback
- No contractor license on application when required
- Incomplete footing depth for frost line
- Missing electrical details for powered garage
